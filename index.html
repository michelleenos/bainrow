About

This is a collection of hand-picked color palettes I use in generative art / creative coding projects.

Each palette has some 'variants,' which are different combinations of the palette colors sorted into background, stroke (sometimes). Sometimes the variants have one or two different or additional colors as well.

The library contains functions for retrieving these variants as a list, optionally filtered by certain parameters (e.g. only variants with stroke colors, only variants with a dark background color, etc).
